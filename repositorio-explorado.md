# Repositorio explorado

- **Nombre:** JSON for Modern C++
- **URL:** https://github.com/nlohmann/json
- **Qué hace:** es una librería para usar JSON en C++. Es un solo archivo (`json.hpp`) y se usa casi igual que en Python.

## Commits que me llamaron la atención

- `5683f5e` - un arreglo para que compile bien en C++20 con algunos compiladores
- `dcb96e8` - una mejora para que escriba JSON más rápido
- `c7fd5ac` - este lo hizo un bot (dependabot) que actualiza las dependencias solo

## Qué aprendí

Los mensajes de commit son cortos y casi todos llevan al final el número del pull request. También vi que en proyectos grandes hay bots que hacen commits.
